**Sou estudante de TADS**, a princípio focado em Back-End. Neste repositório voltado para os estudos está registrada a compilação organizada do meu processo de aprendizagem. Todo o material relevante que eu desenvolvo através das aulas acadêmicas e cursos realizados em plataformas online, assim como testes e exercícios, serão disponibilizados neste ambiente.


## Conteúdo do Repositório
> o conteúdo deste repositório é constamente atualizado conforme a grade dos estudos.

A finalidade deste conjunto é apresentar as etapas do meu desenvolvimento, disponibilizando todo o material consumido e criado, a fim de apresentar todos os conceitos que estou tendo contato durante minha aprendizagem. Para isso, o processo apresentado irá desde os princípios básicos da programação até a criação de scripts atra´veis de exercícios, testes, e pequenos projetos.

  * **Sintaxe**
  * **Operadores**
  * **Entrada e Saída de dados**
  * **Manipulação de dados**
  * **Controle Condicional**
  * **Estrutura de Repetição**
  * **Estrutura de dados**
  * **Funções** 
  * **Exercícios/Enunciados**

  Dentro deste mesmo tópico há uma sessão somente que aborda termos e aplicações estudadas com base na leitura do livro *[​"📕Entendendo Algoritmos"](https://www.amazon.com.br/Entendendo-Algoritmos-Ilustrado-Programadores-Curiosos/dp/8575225634)* escrito por Aditya Bhargava.

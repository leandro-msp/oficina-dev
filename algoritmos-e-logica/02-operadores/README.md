# OPERADORES
Neste trecho de estão presentes todo conteúdo que apresenta a funcionalidades dos operadores dentro das linguagem, sendo eles:
* **Aritiméticos =>** (Soma, Subtração, Multiplicação, Divisão, Módulo/Resto, expoente)
* **Atribuição =>** (formas de atribuição de valores)
* **Relacionais =>** (Igual e Diferente, Maior e menor, Menor igual e Maior Igual)
* **Lógicos =>** (Negação, OU, E, OU Exclusivo, Ternário)

Estes operadores possuem uma função comum em todas as linguagens de programação, realizar cálculos, atribuir valores, comparar dados, e retornar um valor lógico (verdadeiro ou falso). Por mais que cada linguagem possui suas particularidades de sintaxe, os operadores não agem de maneira diferente em cada uma, o que pode alterar é a simbologia, entretanto trabalham com a mesma proposta.

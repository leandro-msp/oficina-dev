### Variáveis:
É um espaço na memória do computador reservado para armazenar dados que podem ser modificados/alterados conforme a execução do código/programa.

### Tipos de Dados:
Toda linguagem de programação utiliza tipos de dados para processar as informações, sendo as princpais abordadas neste trecho:
    
* **String =>** Textos ou caracteres delimitados por aspas.(ex.: "Olá Mundo!").
* **Int/Float =>** tipo de dado que trata exclusivamente de números, sendo Int os números inteiros(5,10,100) e o Float números decimais (8.5 | 0.6).
* **Boolean =>** Valores lógicos , sendo eles apenas Verdadeiro (true) ou Falso(false). A considerar que segue a lógica binária (true = 1) e (false=0).

**CONSTANTE:**
Assim como uma variável ela armazena um dado, porém com uma particularidade, este valor não pode ser alterado(em Python não uma função específica para declarar uma função, para este tipo de casa é usado o "senso" do programador. Quando trata-se de criar uma "constante" utiliza todas as letras maiúsculas, desta forma o dev se atenta caso precise chamar aquele valor.).

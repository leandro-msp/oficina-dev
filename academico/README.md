# ​​​​📚​ Acadêmico

Este repositório foi criado para organizar e centralizar todos os conteúdos, projetos e atividades práticos desenvolvidos ao longo das **disciplinas da faculdade**. Cada pasta representa um módulo ou matéria específica do setor acadêmico.

---

## ​​​🗂️​ Estrutura de Pastas

Abaixo está a descrição do que é abordado em cada subpasta deste diretório:

* **🗄️`DEV-BD-1S-3MM`** 
  * **Foco:** Desenvolvimento em Banco de Dados.
  * **Conteúdo:** Fundamentos SQL, tabelas, queries de consultas e manipulação, testes e exemplos.

* **🌐​`DEV-WEB-3S-1M`**
  * **Foco:** Desenvolvimento Web.
  * **Conteúdo:** Projetos práticos, conceitos de front-end, como: HTML, CSS.

* **🐍​`displinas_cPython`**
  * **Foco:** Lógica de programação e desenvolvimento com Python nas discplinas de Aprendizado de Máquina e Ciência de Dados.
  * **Conteúdo:** Scripts, algoritmos, estruturas de dados e exercícios práticos utilizando a linguagem Python.

* **​🖱️​`FE-JS-3S-1MMM`**
  * **Foco:** Front-End com JavaScript.
  * **Conteúdo:** Manipulação do DOM, interatividade em páginas web e lógica aplicada ao ecossistema JavaScript.

* **​​🥷​`PBE-1S-3MM`**
  * **Foco:** Programação Back-End com PHP.
  * **Conteúdo:** Fundamentos e particularidades da linguaguem, Integrando Back-End em formulários, Controle de Sessão e Banco de Dados.

---

## 🚀​ Tecnologias Utilizadas

O desenvolvimento destas disciplinas envolve o uso de ferramentas e linguagens modernas, incluindo:

* **Linguagens de Programação:** Python, JavaScript, PHP
* **Desenvolvimento Web:** HTML5, CSS3
* **Ambiente de Desenvolvimento:** VS Code, Git e GitHub, e ferramentas web, sendo: One Compiler, W3Schools.

---

## ​🎯​ Objetivos 

1. **Fixação de Conteúdo:** Praticar a teoria vista em sala de aula através de códigos reais.
2. **Histórico de Evolução:** Manter um registro visual do progresso técnico ao longo dos semestres.
3. **Portfólio Acadêmico:** Servir de base para consultas futuras e demonstração de habilidades.

## ​​ℹ️​ Orientações
* **Cada pasta** possui um guia para testar os códigos. Nenhum deles será necessário a instalação de programas ou servidores pesados para rodar os testes.
    * **PHP** -> PHP 8.X
    * **JS** -> Node e npm (recomenda-se a extensão Live Server do VS Code)
    * **Python** -> conta com um ambiente virtual embutido (.venv)
